Just wanted to preface this by saying, I didnt use an agent, and I used the llm a couple of times.
1. What was the breakthrough that moved the work forward?
    There were a couple. First I think the big one was looking at other people's work who have done retro websites and retro site style, this really inspired me as well as looking at the html of these sites. Luckily they're mostly just plain html and css that is handwritten so pressing inspect element and looking at html + css is very easy and often very logical (try finding out how a modern website does something magical by clicking inspect elements -- you'll be there for a while 9/10). Hence, this really inspreid me and moved my work forward.
2. What did this work change about who I want to be as a software developer?
    This work really made me think differently. I've done lots of web development in the past especially with javascript frameworks, but there's something so easy and simple about just pure html and css. It's really quite fun as well being put into this restrictive environment for the purposes of the crit. Hence, I think this has really improved my flexibility as a software developer as I was often presented with things not possible without javascript, and really made me think in terms of plain css (which can do a surprisingly large amount of things). I'd love to make more sites like this as it is really quite interesting, fun, and simple with little nonsense from say react state management where i have to make an x-state machine with like 13 billion states in order to make anything work.
